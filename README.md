# Работа с расписанием и хеш-таблицей на C++

Учебный проект, написанный на втором курсе университета в рамках курса **СиАОД — «Структуры и алгоритмы обработки данных»**.

Консольная программа для хранения и обработки записей расписания. Основная задача — реализовать собственную хеш-таблицу для доступа к записям бинарного файла и сравнить поиск по хеш-таблице с линейным поиском.

Репозиторий опубликован как архив учебной работы.

## Возможности

- Генерация текстового файла со 100 000 тестовых записей.
- Преобразование текстового файла в бинарный и обратно.
- Построение хеш-таблицы, связывающей ID записи с её позицией в файле.
- Поиск и удаление записей по ID через хеш-таблицу.
- Вывод содержимого бинарных файлов в консоль.
- Формирование расписания группы на выбранный день.
- Базовая обработка конфликтов аудиторий.
- Замер времени поиска для ID `0`, `50000` и `99999` двумя способами: через хеш-таблицу и последовательным чтением файла.

## Реализация

Хеш-таблица реализована вручную: коллизии разрешаются методом цепочек, а при превышении порога заполнения размер таблицы увеличивается вдвое с повторным хешированием элементов.

Записи хранятся в бинарном файле как структуры `Schedule` фиксированного размера. Хеш-таблица содержит числовой ключ и позицию записи, поэтому после поиска ключа программа читает запись по смещению `position * sizeof(Schedule)`.

Удаление через хеш-таблицу обнуляет запись в файле без уменьшения его размера. При выводе и преобразовании в текст пустые записи пропускаются.

## Формат данных

Каждая строка исходного текстового файла содержит восемь полей, разделённых `;`:

```text
ID;Группа;Предмет;Номер пары;Номер недели;День недели;Тип занятия;Аудитория
```

Пример сгенерированной записи:

```text
00000;Group000;Subject0;PairNum0;WeekNum0;Weekday1;Lecture;Room5;
```

## Сборка и запуск

Понадобится компилятор C++ с поддержкой C++11 или новее.

Сохраните исходный код в `main.cpp` и добавьте к заголовкам:

```cpp
#include <chrono>
```

Пример сборки с GCC или Clang:

```bash
mkdir -p build
c++ -std=c++11 -O2 main.cpp -o build/schedule
cd build
./schedule
```

Запуск из каталога `build` позволяет разместить выходные файлы в корне проекта: пути к ним в исходном коде начинаются с `../`.

## Использование

Для первого запуска выберите последовательно:

1. **Пункт 1** — создать тестовый текстовый файл.
2. **Пункт 2** — преобразовать его в бинарный и построить хеш-таблицу.
3. **Пункт 5** — найти запись по ID, либо **пункт 10** — сравнить время поиска.
4. **Пункт 9** — завершить программу.

Хеш-таблица хранится только в памяти. После перезапуска её нужно заново построить через пункт 2. Для повторной конвертации рекомендуется перезапустить программу: существующая таблица перед конвертацией не очищается.

## Ограничения учебной версии

Проект сохраняет особенности исходной учебной реализации:

- Поиск и удаление отсутствующего ключа могут привести к аварийному завершению из-за неполной проверки указателей.
- Формирование расписания на день ожидает числовые значения группы и дня, тогда как генератор записывает строки вида `Group000` и `Weekday1`. Для работы этой функции требуется согласовать форматы.
- Обработка конфликтов меняет аудиторию только у одной записи, не учитывает номер недели и не проверяет, свободна ли выбранная аудитория.
- Длина входных строк не проверяется перед копированием в массивы фиксированного размера.
- Бинарный формат представляет собой прямую запись структуры в файл и не рассчитан на перенос между разными платформами.
- Замеры времени выполняются по одному разу для каждого ключа и служат учебной демонстрацией, а не полноценным бенчмарком. Их лучше запускать до удаления записей.
